# Chapter 4 FactSet Industry Enrichment Spec

## Purpose
Add broad, reproducible industry labels to Chapter 4 analysis nodes so the semiconductor-relevance codebook can classify nodes beyond the strict semi-labeled subset.

This enrichment is built from FactSet SQL and mapped back to `analysis_uid`.

## Scope
- Snapshot: `2025-06-09` (config-driven)
- Node universe: `artifacts/ch4/v2_fix01/2025-06-09/m0/node_table_contract.parquet`
- ID mapping:
  - preferred: `rep_factset_entity_id`
  - fallback: `rep_scr_node_id -> canonical_id` via `data/processed/core/releases/core_v1/mapping/entity_map.parquet`

## SQL Sources and Fields
### 1) SIC (broad coverage)
- Table: `sym_v1.sym_entity_sector`
- Fields:
  - `factset_entity_id`
  - `primary_sic_code`
  - `industry_code`
  - `sector_code`

### 2) RBICS L2 (broad coverage)
- Tables:
  - `sym_v1.sym_entity_sector_rbics` (`factset_entity_id`, `l2_id`, `focus_flag`)
  - `ref_v2.rbics_structure_l2_curr` (`l2_id`, `l2_name`, `l1_id`, `l1_name`)
- Join: `sym_entity_sector_rbics.l2_id = rbics_structure_l2_curr.l2_id`
- Entity-level reduction:
  - Primary L2: highest `focus_flag`, tie-break by `l2_id`
  - Also keep `l2_count`, `l2_ids` (pipe-separated), `l2_names` (pipe-separated)

### 3) RBICS L4 (precision layer)
- Tables:
  - `rbics_v1.rbics_bus_seg_report` (`report_id`, `factset_entity_id`, `period_end_date`)
  - `rbics_v1.rbics_bus_seg_item` (`report_id`, `l6_id`, `revenue_pct`)
  - `rbics_v1.rbics_structure` (`l6_id`, `l4_id`, `l4_name`)
- Joins:
  - `bus_seg_report.report_id = bus_seg_item.report_id`
  - `bus_seg_item.l6_id = rbics_structure.l6_id`
- As-of filter:
  - `period_end_date <= <snapshot_date>`
- Entity-level reduction:
  - Keep latest report period <= as-of
  - Top L4 in latest report by `revenue_pct` (`rbics_l4_top_id`, `rbics_l4_top_name`)
  - Also keep `l4_count_latest`, `l4_ids_latest`, `l4_names_latest`

### 4) RBICS Coverage Flags
- Table: `rbics_v1.rbics_coverage`
- Fields:
  - `actively_covered`
  - `focus_flag`
  - `revenue_flag`
  - `tradename_flag`
