This folder contains reproducible scripts to analyze structural vulnerabilities in
the **strict** DoD‑anchored semiconductor supply‑chain network constructed in
Chapter 3.

## Running the Full Pipeline

The production entry point is `run_pipeline.sh`, which executes all M0–M9
modules plus the 8 reporting export scripts in dependency order:

```bash
# Full pipeline (requires Ch3 artifacts in artifacts/ch3/network_upstream/)
bash src/analysis/chapter4/run_pipeline.sh \
  --config src/analysis/chapter4/config/ch4_v2_fix01.yaml

# Skip FactSet DB enrichment (M9.2) for offline runs without DB credentials
bash src/analysis/chapter4/run_pipeline.sh \
  --config src/analysis/chapter4/config/ch4_v2_fix01.yaml \
  --skip-m9-2

# Run modules only (skip reporting exports)
bash src/analysis/chapter4/run_pipeline.sh \
  --config src/analysis/chapter4/config/ch4_v2_fix01.yaml \
  --skip-reporting
```

The pipeline performs a pre-flight check for required Ch3 input artifacts
and exits with an error if they are missing. All modules use `set -euo pipefail`
(fail-fast on any error).

## Manually Maintained Report Assets

The following report assets are not fully auto-generated by the pipeline and
require manual attention after any pipeline rerun:

**Table 4.2** (`report/tables/tab_4.2_strict_top25_observed.tex`):
The export script (`reporting/export_table_4_2_strict_top25.py`) produces a
6-column table including a Confidence column (High/Medium/Low, computed from
cross-view presence in the strict Top-25). The deployed report table uses a
5-column layout without the Confidence column. If regenerating, reconcile
the column set with the report's `tabularx` formatting.

**Figure 4.4 action matrix** (`report/figures/fig_4.4_action_matrix.tex`):
This TikZ figure is manually authored. The quadrant counts (n=182, 21, 257,
588; total N=1,048) are hardcoded in the LaTeX source. The export script
(`reporting/export_figure_4_3_numbers.py`) produces the underlying data as
CSV and JSON but does not generate the `.tex` file. After a pipeline rerun,
update the hardcoded counts in the `.tex` file from the CSV output.

**Table C.2** (`report/tables/tab_c.2_adjacent_uncertain_top25_empirical.tex`):
This table has no generating script in the reporting suite. It was manually
formatted from the M0_7 semantic lens output (the adjacent/uncertain stream
from `node_semiconductor_lens_decisions.csv`). After a pipeline rerun,
extract the updated Top-25 adjacent/uncertain candidates from the M0_7
artifacts and reformat as LaTeX.
